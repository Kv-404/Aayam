# Code of conduct

This project is open to students, faculty, and outside contributors.

- Be direct and respectful.
- Critique the change, not the person.
- Do not post PINs, session tokens, private emails, or other secrets in issues, pull requests, or chat.
- Harassment, slurs, and unwanted sexual attention are not accepted.

Maintainers may edit or close a comment, issue, or pull request that breaks these rules, and may block a repeat offender. Report a conduct problem the same way as a security issue: a private advisory at https://github.com/Kv-404/Aayam/security/advisories/new
