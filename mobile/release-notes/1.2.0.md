**Uninstall the old Aayam app first.** 1.2.0 has a new signing key, so it cannot install over 1.1.0. Pick your class again after installing. Later versions install over 1.2.0 as normal updates.

**New**
- The app looks like the website: same switches, day and view pickers, header and cards.
- Swipe left and right between days. New Week view with swipeable day columns. The app remembers Day or Week.
- Tap the Aayam logo to go to the home screen; "Continue to …" takes you back.
- Home-screen widgets: Next class and Today.
- The app tells you when a new version is out and offers the download.

**Fixed**
- Now/Next and the NOW mark use the phone's clock, so they no longer go stale.
- Updates no longer miss changes to your shared classes or batch-wide changes.
- A server error shows your saved timetable instead of an error screen.
- Notification taps, the notice list and Google Meet links no longer misbehave or crash.
